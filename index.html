Key Advantages

왜 '보내고' 인가요?

방송을 보내는 장비라서 '보내고'라고 부릅니다. 담당자 누구나 기억하기 쉽고 친근한 직관적인 이름입니다.

2.7인치 LCD 모니터링

별도의 외장 모니터 없이도 전면 LCD를 통해 영상이 실시간으로 차질 없이 정상 송출되고 있는지 즉시 확인 가능합니다.

Dual RTMP & 자동 녹화

듀얼 RTMP 스트리밍을 지원하며, RTMP 설정 시 방송 송출과 동시에 자동으로 녹화가 시작되어 방송 누락을 방지합니다.

동시 인코딩 & 레코딩

고화질 라이브 인터넷 방송 스트리밍과 동시에 USB 포트 및 SD 카드 슬롯을 통한 고화질 동시 녹화를 완벽 지원합니다.

IP 접근 제어 기본 탑재

외부 인가되지 않은 무단 접속을 완벽 차단하며, 미리 등록된 운영 PC에서만 안전하게 접속 및 제어가 가능합니다.

Hardware Interfaces

후면 입출력 단자 상세 구성

다양한 방송 인프라와의 완벽한 연결성과 전원/백업 이중화 호환 설계

4K30 HDMI IN & 3G-SDI IN

• 지원 해상도: HD, Full HD, UHD (4K30p)
• 연결 대상: PTZ 카메라, 스튜디오 믹서
• 특징: HDMI와 방송 전용 SDI 동시 탑재

BALANCED AUDIO (L/R)

• 채널 구성: 좌/우 2채널 스테레오 잭
• 연결 대상: 의회 마이크 앰프, 음향 믹서
• 특징: 노이즈 없는 깨끗한 오디오 입력

IP / PoE (10/100/1000M)

• 네트워크: 기가비트 이더넷 포트
• 전원 공급: PoE (IEEE 802.3af 표준)
• 특징: 랜케이블 하나로 전원+데이터 동시 처리

SD CARD Slot & 레코딩

• 저장 매체: 후면 SD 카드 (전면 USB 지원)
• 동작 연동: RTMP 송출 시 자동 동시 저장
• 특징: 네트워크 장애 시 안전 백업

TALLY Control Port

• 신호 제어: 방송 상태 TALLY 인디케이터
• 특징: 외부 신호등 및 방송 준비 상태 연동

DC 12V Power Jack

• 전원 사양: AC to DC 전용 어댑터 연결
• 특징: PoE 없는 환경에서도 안정 구동

Web Management GUI
